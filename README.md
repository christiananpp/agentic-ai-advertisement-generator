# Multi-Agent AI Advertisement System

Sistem berbasis Artificial Intelligence (AI) yang dikembangkan untuk membantu proses pembuatan konten iklan media sosial secara otomatis menggunakan pendekatan Multi-Agent System dan Large Language Model (LLM).

Project ini dibangun menggunakan Streamlit dan CrewAI sebagai bagian dari penelitian dan Tugas Akhir.

---

## Deskripsi Proyek

Sistem ini menggunakan beberapa AI Agent yang bekerja sama dalam menghasilkan konten iklan, seperti:

- Agent pencari fakta dan informasi
- Agent pembuat konten iklan
- Agent penyusun konsep dan alur konten
- Agent penyempurna hasil iklan

Dengan pendekatan Agentic AI, setiap agent memiliki tugas dan perannya masing-masing untuk menghasilkan output yang lebih optimal dan relevan.

## Cara Menjalankan Project

### 1. Clone Repository

```bash
git clone https://github.com/christiananpp/multi-agent-ai-advertisement-system.git
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Jalankan Streamlit

```bash
streamlit run app_crewai.py
```

## Catatan Penting

Project ini menggunakan API Key dan konfigurasi environment yang bersifat rahasia.

Karena alasan keamanan, file API Key tidak disertakan pada repository publik GitHub ini.

Silakan membuat file `.env` atau menambahkan environment variable sendiri sebelum menjalankan aplikasi.

Contoh:

```env
OPENAI_API_KEY=your_api_key_here
```
