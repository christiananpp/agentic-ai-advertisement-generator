# Sistem Multi-Agent AI untuk Pembuatan Konten Iklan Otomatis

Proyek ini merupakan sistem berbasis Artificial Intelligence (AI) yang dikembangkan untuk membantu proses pembuatan konten iklan media sosial secara otomatis menggunakan pendekatan Multi-Agent System dan Large Language Model (LLM).

Aplikasi ini dibangun menggunakan Streamlit dan CrewAI sebagai bagian dari Tugas Akhir.

---

## Deskripsi Proyek

Sistem ini menggunakan beberapa AI Agent yang bekerja sama dalam menghasilkan konten iklan, seperti:

- Agent pencari fakta/informasi
- Agent pembuat konten iklan
- Agent penyusun konsep/layout
- Agent penyempurna hasil iklan

Dengan pendekatan Agentic AI, setiap agent memiliki tugas dan perannya masing-masing untuk menghasilkan output yang lebih optimal.
